# DataTableConfig

## 파일
- `DataTableConfig.cs` (ScriptableObject)
- 서버 동기화: Editor JSON Export → 서버 resources/data/DataTableConfig.json

## 항목
- `addShipCosts[]` — 함선 추가 비용 (M/MR, 함선 수 인덱스 기준)
- `pvpListCount` / `pvpListRefreshCount` / `pvpRankScoreInit` / `pvpRankScorePenalty` — PvP 설정
- `moduleUnlockPrice` — 슬롯 unlock 고정 비용
