# 모듈 레벨업 (Module Level Up)
# 슬롯 unlock → std/adv 레벨업 비용 및 진행 구조

## 슬롯 Unlock
- 비용: **5,000 M 고정** (슬롯 타입 무관)
- unlock 즉시 기본 서브타입(t1_m1) Lv.1 모듈 자동 장착

---

## 레벨업 구조
- 최대 Lv.10
- 모듈 인스턴스별 독립 (같은 타입이라도 슬롯마다 레벨 별도)
- std 모듈: M만 소모
- adv 모듈: M + MR 소모 (MR은 std 대비 약 6배)

| level | std cost_m | adv cost_m | adv cost_mr |
|-------|-----------|-----------|------------|
| 1→2   | 100       | 100       | 600        |
| 2→3   | 150       | 150       | 900        |
| 3→4   | 225       | 225       | 1,350      |
| 4→5   | 338       | 338       | 2,025      |
| 5→6   | 506       | 506       | 3,038      |
| 6→7   | 759       | 759       | 4,556      |
| 7→8   | 1,139     | 1,139     | 6,834      |
| 8→9   | 1,709     | 1,709     | 10,253     |
| 9→10  | 2,563     | 2,563     | 15,378     |
| 10→11 | 3,844     | 3,844     | 23,066     |
| **합계** | **~11,333 M** | **~11,333 M** | **~68,000 MR** |

---

## 모듈 진행 흐름

```
[슬롯 unlock]  5,000 M → t1_m1 Lv.1 자동 장착
     ↓
[레벨업 반복]  Lv.1 → Lv.10 (M 소모)
     ↓ Lv.10 도달 + 기술레벨 조건 + 비용 → 서브타입 교체 가능
[서브타입 교체] t2_m1 Lv.1로 교체 (MR 소모, 레벨 리셋)
     ↓
[레벨업 반복]  Lv.1 → Lv.10 (M + MR 소모)
     ↓ 이후 t3, t4... tier 반복
```

→ 서브타입 교체 조건 및 비용은 [module_swap.md](module_swap.md) 참고.
