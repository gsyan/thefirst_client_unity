# My PVP Info / Rank List 탭 전환 구조

## PVP 탭 UI

### 레이아웃
```
┌──────────────────────────────────────────────────────┐
│  [My PVP Info]  [Rank List]                          │  ← 탭 전환 (상단)
├──────────────────────────────────────────────────────┤
│  Score: 1000  (Rank -)                               │  ← 내 점수 / 순위 (My PVP Info 탭)
│                                                      │
│  [Commander1]  [Commander2]  [Commander3]            │  ← 대전 상대 카드 3개
│   Score:1000    Score:900    Score:1100              │
│   Rank 3        Rank 4       Rank 1                 │
│   ⚔ ❤100 🔒0   ⚔ ❤100 🔒0  ⚔ ❤100 🔒0            │
│                                                      │
│                           [Refresh (5/5)]            │  ← 새로고침 (잔여 횟수 표시)
└──────────────────────────────────────────────────────┘
```

### My PVP Info 탭
- 내 PvP 점수 및 현재 순위 표시
- 순위 미산정 시 `(Rank -)` 표시

### Rank List 탭
- 전체 랭킹 리스트 (추후 구현)

### 대전 상대 카드
- 상대 커맨더명 (Commander ID)
- PvP 점수 + 현재 순위
- 함대 스탯 요약 (⚔ATK, ❤HP, 잠금 슬롯 수 등)
- 카드 클릭 → 해당 상대와 PvP 대전 시작

### Refresh 버튼
- 상대 목록 갱신
- 잔여 횟수 표시: `Refresh (N/5)` 형식, 소진 시 비활성화 (추후 쿨타임 또는 광고 시청으로 충전)
