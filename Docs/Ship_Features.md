# 함선 특징 정리 (함체 아키타입)

원본: `Assets/Resources/DataTable/HullArchetypePassive/datatable_hull_archetype_passive.csv`(패시브/해금 조건), `Assets/Resources/Localization/csv/UI.csv`(설명 문구).
이 문서와 CSV가 다르면 CSV가 맞음.

## 패시브/해금 규칙

- 아키타입마다 패시브 4단계
- **1단계**: 기본 지급(문턱 0)
- **2~3단계**: 아키타입별 카운터가 문턱에 도달하면 해금
- **4단계**: 존런 클리어 횟수(`zone_run_clear`)로 해금, **함대 전체**에 적용
- 효과 범위: `self`는 자기 함선만, `fleet`은 함대 전체

## 개요

| 아키타입 | 한글명 | 역할 | 티어 | 슬롯(빔/미사일/격납고) | 2~3단계 해금 카운터 |
|---|---|---|---|---|---|

| leviathan | 리바이어던함 | 수송선(운반+전투) | 3 | 2 / 1 / 2 | 함대 자원 절약량 |

## 아키타입별 상세

형식: 단계 - 조건 - 효과

### centurion (켄투리온함, 범용 전투함)
1. 기본 - 빔 공격력 +10% (자기)
2. 적 함선 10기 파괴 - 미사일 공격력 +10% (자기)
3. 적 함선 20기 파괴 - 함선 체력 +50% (자기)
4. 존런 10회 클리어 - 함대 전체 빔 공격력 +10%

### prism (프리즘함, 빔 특화)
1. 기본 - 빔 공격력 +10% (자기)
2. 적 함선 40기 파괴 - 빔 공격력 +15% (자기)
3. 적 함선 80기 파괴 - 빔 공격력 +20% (자기)
4. 존런 20회 클리어 - 함대 전체 빔 공격력 +20%

### argus (아르고스함, 탐사형 전투함)
1. 기본 - 탐사 기능 활성, 성공 확률 10% (자기)
2. 탐사 100회 성공 - 동시 탐사 2회 (자기)
3. 탐사 3,000회 성공 - 동시 탐사 3회 (자기)
4. 존런 20회 클리어 - 함대 전체 10% 확률로 탐사 활성

### colossus (콜로서스함, 탱커)
1. 기본 - 함선 체력 +100% (자기)
2. 받은 누적 데미지 5,000 - 요격체 활성화 (자기)
3. 받은 누적 데미지 500,000 - 실드 활성화 (자기)
4. 존런 30회 클리어 - 함대 전체 체력 +50%

### leviathan (리바이어던함, 수송선)
1. 기본 - 함대 자원 사용량 -25%
2. 자원 절약 10,000 - 함대 자원 사용량 추가 -25%, 함대 빔/미사일/격납고 공격력 +10%
3. 자원 절약 30,000 - 함대 체력 회복 +50%, 실드 게이지 회복 +50%, 요격체 재충전 시간 -0.3초
4. 존런 30회 클리어 - 버서커: 자원이 50%/30%/10% 미만이면 함대 공격력 2배/3배/4배

### corsair (코르세어함, 약탈선)
약탈: 함재기가 함선을 명중시킬 때마다 확률로 광물 약탈. 기본 확률 10%.
1. 기본 - 함재기 약탈 확률 +10% (자기)
2. 약탈 광물 5,000 - 함재기 약탈 확률 +10% 추가 (자기)
3. 약탈 광물 500,000 - 함재기 약탈 확률 +10% 추가 (자기)
4. 존런 40회 클리어 - 함대 전체 약탈 확률 +10%

### talon (탈론함, 공격 특화)
1. 기본 - 빔 공격 시마다 공격력 +5% 누적, 최대 +50% (자기)
2. 적 함선 40기 파괴 - 미사일 침묵(재장전 지연) 지속시간 2배 (자기)
3. 적 함선 400기 파괴 - 격납고(함재기) 공격력 +100% (자기)
4. 존런 40회 클리어 - 함대 전체 빔/미사일/격납고 공격력 +50%

### vulcan (불카누스함, 폭탄선)
1. 기본 - 미사일 폭발 범위 +100% (자기)
2. 적 함선 40기 파괴 - 미사일 공격력 +100% (자기)
3. 적 함선 400기 파괴 - 미사일 속도 +100% (자기)
4. 존런 40회 클리어 - 함대 전체 미사일 공격력, 속도 +100%

### nemesis (네메시스함, 치명타 특화)
1. 기본 - 빔 치명타 확률 +5% (자기)
2. 적 함선 50기 파괴 - 미사일 치명타 확률 +5% (자기)
3. 적 함선 500기 파괴 - 격납고 치명타 확률 +5% (자기)
4. 존런 50회 클리어 - 함대 전체 치명타 확률 +5%

### phoenix (피닉스함, 수리함)
1. 기본 - 아군 함선 수리 능력 활성화 (동시 1척)
2. 아군 수리량 50,000 - 동시 2척 수리
3. 아군 수리량 5,000,000 - 동시 3척 수리
4. 존런 50회 클리어 - 함대 전체 체력 +100%

### halcyon (할시온함, 실드 회복함)
1. 기본 - 아군 함선 실드 게이지 회복 부스트 활성화 (동시 1척)
2. 아군 실드 충전량 50,000 - 동시 2척 부스트
3. 아군 실드 충전량 5,000,000 - 동시 3척 부스트
4. 존런 50회 클리어 - 함대 전체 실드 게이지 +100%

### aegis (이지스함, 실더)
1. 기본 - 실드, 요격체 활성화
2. 실드 흡수 데미지 50,000 - 실드 데미지당 게이지 소모 -10% (자기)
3. 실드 흡수 데미지 5,000,000 - 실드 게이지 +100% (자기)
4. 존런 50회 클리어 - 함대 전체 실드 데미지당 게이지 소모 -10%

### sentinel (센티넬함, 요격자)
1. 기본 - 실드, 요격체 활성화
2. 요격 1,000회 - 요격체 1기가 미사일 2발 방어 (자기)
3. 요격 5,000회 - 요격체 재충전 시간 -0.3초 (자기)
4. 존런 50회 클리어 - 함대 전체 요격체 재충전 시간 -0.2초

## 카운터 종류

| counter_type | 의미 |
|---|---|
| `destroy_enemy_ship` | 적 함선 파괴 수 |
| `scout_success` | 탐사 성공 횟수 |
| `damage_taken_cumulative` | 받은 누적 데미지 |
| `fleet_resource_saved` | 함대 자원 누적 절약량 |
| `scavenge_mineral` | 약탈로 얻은 누적 광물량 |
| `ally_repair_amount` | 아군 수리 누적 체력량 |
| `ally_shield_charge_amount` | 아군 실드 게이지 누적 충전량 |
| `shield_absorb_amount` | 실드로 흡수한 누적 데미지 |
| `intercept_count` | 요격 성공 횟수 |
| `zone_run_clear` | 존런 클리어 횟수(전 아키타입 4단계 공통) |

## 특수 메커니즘

- **함재기 약탈**: 함재기가 함선을 명중시킬 때마다 각자 독립적으로 확률 롤. 기본 10% + corsair 패시브. 성공 시 광물 10/20/30/40/50 중 균등 랜덤 1개 획득. 함재기끼리의 명중은 제외. 셀 클리어 시점에 집계해서 표시.
- **탐사(argus)**: 약탈과 완전히 별개. argus 자신이 5초 간격으로 확률 롤(기본 10%). 성공 시 3D 공간에 "탐사 성공" 플로팅 텍스트 표시 + 광물 획득. 2~3단계는 동시 탐사 슬롯 증가(슬롯마다 독립 롤), 4단계는 함대 전체로 전파되고 본인은 20%로 상승.
- **폭탄선(vulcan)**: 미사일 스플래시 데미지는 이미 구현됨. vulcan 전용 추가 폭발이 별도로 필요한지는 구현 전 재확인 필요.
- **버서커(leviathan 4단계)**: 남은 자원에 따라 함대 공격력 배율이 달라짐. 구체 스펙은 미확정.
- **실드/요격체 해금**: 슬롯은 함체 구조상 항상 설치되고, 사용 가능 여부는 출력 시점(`FleetService.buildModuleHullInfoDto`)에 판정. 내 함대/PVP 상대/랭킹 공통.
